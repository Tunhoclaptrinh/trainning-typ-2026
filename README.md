# Backend Training Program

## Tổng quan

Chương trình training Backend trong 6 tuần, gồm 5 tuần học lý thuyết + thực hành và 1 tuần làm project tổng hợp.

| 3 | Authentication & Authorization | [week-3](./week-3) |
| 4 | Message Queue | [week-4](./week-4) |
| 5 | Caching & Redis | [week-5](./week-5) |

## Nộp bài

Xem hướng dẫn nộp bài tại [Hướng dẫn](https://github.com/quanglam04/trainning-typ-2026/issues/5)

## Yêu cầu chung

- Mỗi tuần cần **trình bày lý thuyết** (có thể viết markdown hoặc slide)
- Phần thực hành cần có **demo** (ảnh chụp, video, hoặc hướng dẫn chạy)
- Code phải chạy được, có hướng dẫn setup trong README

## Tổ chức nội dung và mã nguồn

- Báo cáo, lý thuyết, hướng dẫn demo và ảnh minh chứng được lưu tại repo này.
- Mã nguồn backend, SQL, seed, benchmark và demo thực thi tập trung tại [EruSentia-Server](https://github.com/Tunhoclaptrinh/EruSentia-Server).
- Các đoạn code trong tài liệu là ví dụ giải thích bài học; hướng dẫn chạy dẫn về repo backend.
